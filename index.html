Simple 3-Step Process

How SkillSwap Works

No money, no subscriptions. Pure student-to-student skill barter.

1

List Your Skills

Post what you can teach (e.g., Python, Figma) and what you want to learn (e.g., Guitar, German) in return.

2

Connect & Swap

Browse listings or use our matching algorithm to send exchange proposals to compatible campus peers.

3

Learn & Grow Together

Meet online or in-person on campus, teach each other, and leave helpful peer feedback and ratings.

BTech Lab Project

Built for BTech Web Technology Lab

SkillSwap demonstrates modern, accessible, and clean client-side web engineering. It uses semantic HTML5 tags, CSS3 responsive grid and flexbox, vanilla JavaScript DOM manipulation, and browser LocalStorage for complete data persistence without external dependencies.

Read Viva Guide & Architecture

Project Highlights:

  • 100% Pure HTML5, CSS3 & Vanilla JavaScript
  • Works offline by double-clicking index.html
  • Zero passwords stored (compliant with lab rules)
  • Seeded with 8 students, 20 skills & 6 categories
  • Responsive breakpoints: 1024px, 768px, 480px
